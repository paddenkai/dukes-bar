DUKE'S BAR — one app, two tools
================================
A single installable web app:
  • Home hub -> tap into Bar Book, Study, or Favorites
  • Bar Book: search any drink, A-Z or grouped By Type, star favorites
  • Study: Cards / Quiz / Build, filter by category or "★ Faves"
  • Favorites sync across both sides (saved on your device)

ADD TO IPHONE HOME SCREEN
1. Push this "dukes-app" folder to GitHub (e.g. paddenkai/dukes-app)
   and enable GitHub Pages (Settings > Pages > main / root).
2. URL: https://paddenkai.github.io/dukes-app/
3. Open it in SAFARI -> Share -> Add to Home Screen -> Add.
4. Opens full-screen, works offline after first load. One icon.

When you update it later, bump CACHE "dukes-bar-v1" -> v2 in sw.js.
